# Security Policy

## Supported versions

Security fixes are released for the latest `1.x` only.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Report vulnerabilities privately — never via public issue. Use [GitHub Security Advisories](https://github.com/JovianOps/beacon/security/advisories/new).

Include the affected version, the environment signals involved, and expected impact. Accepted reports are fixed and published together with reporter credit unless anonymity is requested.

## Scope

In scope: tier misdetection that could apply production settings locally (or vice versa), override bypasses, multi-platform handling.

Not vulnerabilities here: findings in consuming applications' own settings logic.
